Jamble allows users to invite friends to join the app using a referral system. This feature rewards eligible users when referral conditions are met.

## Sharing Your Invite Code

Each Jamble user has a unique invite code.

To share your invite code:

- Open the Jamble app
- On profile, click on “invite friends”
- Click on “Share Friends”
- Select the channel (SMS, mail, whatsAapp) copy code

Invite codes are personal and must not be sold, misused, or shared in a misleading way.

---

## Using a Referral Code

New users can use a referral code when joining Jamble.

To use a referral code:

- Download the Jamble app
- Start the account creation process
- Redeem the referral code
   - go to your profile > settings > redeem a code
- You cannot accumulate 2 codes
- Once you redeem a code on a device, you cannot create a new account to redeem a code

Referral codes must be entered:

- After completing account creation
- before you purchase
- within 48h after account creation

Your friend will get their referral reward once you purchase within 14 days.

Referral codes cannot be applied after eligibility conditions have passed.

---

## Referral Rules

To ensure fairness and prevent abuse, the following rules apply:

- Referral rewards are limited to eligible users only
- Self-referrals are strictly prohibited and will lead to account restriction
- Creating multiple accounts on different devices to gain rewards is not allowed
- Jamble reserves the right to modify or suspend the referral program at any time
