A Jamble permite que os usuários convidem amigos para entrar no app por meio de um sistema de indicação. Essa funcionalidade recompensa usuários elegíveis quando as condições da indicação são cumpridas.

---

## Compartilhar seu código de convite

Cada usuário da Jamble possui um código de convite único.

Para compartilhar seu código de convite:

- Abra o aplicativo Jamble
- Acesse seu perfil e toque em **“Convidar amigos”**
- Clique em **“Compartilhar convite”**
- Escolha o canal (SMS, e-mail, WhatsApp) ou copie o código

Os códigos de convite são pessoais e não podem ser vendidos, utilizados de forma indevida ou compartilhados de maneira enganosa.

---

## Usar um código de indicação

Novos usuários podem usar um código de indicação ao entrar na Jamble.

Para usar um código de indicação:

- Baixe o aplicativo Jamble
- Inicie o processo de criação da conta
- Resgate o código de indicação:
   - vá em **Perfil > Configurações > Resgatar um código**
- Não é possível acumular dois códigos
- Após resgatar um código em um dispositivo, não é permitido criar uma nova conta para resgatar outro código

Os códigos de indicação devem ser inseridos:

- Após concluir a criação da conta
- Antes de realizar a primeira compra
- Dentro de até **48 horas** após a criação da conta

Seu amigo receberá a recompensa por indicação assim que você fizer uma compra dentro de 14 dias.

Códigos de indicação não podem ser aplicados após o prazo ou fora das condições de elegibilidade.

---

## Regras de indicação

Para garantir a equidade e evitar abusos, aplicam-se as seguintes regras:

- As recompensas de indicação são limitadas a usuários elegíveis
- Autoindicações são estritamente proibidas e podem resultar em restrições na conta
- A criação de múltiplas contas em diferentes dispositivos para obter recompensas não é permitida
- A Jamble se reserva o direito de modificar ou suspender o programa de indicação a qualquer momento
